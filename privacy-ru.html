Конфиденциальность

Владелец: Ivan Kukin · growlog.app.support@gmail.com

Данные на устройстве

GrowLog хранит на устройстве записи о садах, растениях, задачах, уходе, проблемах, замерах, урожае, средствах, фотографии и сохранённые ответы ИИ. Местоположение сада необязательно. В текущей версии нет аккаунта GrowLog или автоматической синхронизации сада через сервер GrowLog. Резервное копирование самого устройства регулируется настройками iOS.

Вы можете экспортировать резервную копию с записями, фотографиями, ответами ИИ и точными координатами, если они указаны. GrowLog не загружает её на свой сервер автоматически. Файлы, переданные через «Поделиться», обрабатываются выбранным вами получателем или сервисом по его правилам.

Местоположение и календарь

Для погоды и климатического календаря используются точные координаты выбранного места. Приложение не отслеживает перемещения в фоне. Прогноз запрашивается у Open-Meteo.

Координаты для календаря передаются сервису GrowLog на Cloudflare. Если профиль места ещё не подготовлен, координаты используются в сборке через GitHub Actions по данным Copernicus ERA5-Land и высоты местности. Они могут присутствовать в параметрах сборки и служебных файлах. Записи о растениях для такой сборки не нужны.

Подготовленные профили с координатами хранятся на Cloudflare для повторного использования. Готовый профиль места может быть доступен по его координатам без входа в приложение. Он не содержит дневник сада, фотографии или имя владельца. Это общий климатический набор для места; связь запроса с идентификатором доступа хранится отдельно в учёте лимитов. Автоматический срок удаления профилей пока не настроен. Удаление связанных с пользователем записей не означает автоматического удаления общего профиля для всех. Файлы результатов GitHub Actions хранятся 14 дней по текущей настройке; это не срок хранения всех журналов GitHub или серверных копий.

Данные для ИИ

ИИ запускается по вашему действию. Перед первой передачей и после изменения версии согласия приложение показывает пояснение. Если отказаться, запрос не отправится. Согласие хранится локально. В разделе «Профиль → О GrowLog → Передача данных ИИ» можно повторно открыть пояснение и отозвать согласие. После отзыва следующий ИИ-анализ снова потребует подтверждения. Отзыв не удаляет уже переданные данные или сохранённые ответы; записи сада остаются доступны.

Для выбранного анализа GrowLog отправляет через свой сервер в Cloudflare Workers AI текстовые сведения: культуру, сорт, стадию, условия выращивания, описание проблемы, наблюдения, относящиеся к запросу записи ухода и сведения о средствах. Заметки могут содержать личные сведения, которые вы в них включили.

Координаты из поля местоположения заменяются приблизительным регионом с округлением до 0,1°. Фотографии в текущие ИИ-запросы не входят. Округление координат не удаляет точный адрес или другие личные сведения из ваших заметок: не включайте их в запрос без необходимости.

Слой восстановления GrowLog не сохраняет исходное тело ИИ-запроса. Он может временно сохранить готовый ответ на сервере, чтобы повтор соединения не создавал новый анализ. Ответ доступен для восстановления 15 минут, затем исключается из выдачи и удаляется автоматической очисткой. Это не обещание удаления всех резервных копий и технических журналов поставщиков за 15 минут. Сохранённый в приложении ответ остаётся на устройстве до удаления вами.

Cloudflare заявляет, что не использует содержимое Workers AI для обучения моделей или улучшения сервисов без явного согласия клиента. Отдельное хранение в сервисах Cloudflare регулируется настройками хранения и условиями поставщика. Правила Workers AI.

История растения для вашего ИИ

Выгрузка создаётся на устройстве без вызова ИИ GrowLog. Она включает факты и даты из истории выбранного растения, условия и замеры текущей зоны. Координаты текущего сада округляются до 0,1°. Фотографии и выводы нашего ИИ исключены, ваши заметки сохраняются. Проверьте текст перед копированием или передачей файла. Другой ИИ обрабатывает переданные данные по правилам выбранного вами сервиса.

Лимиты и подписка

Сервис хранит идентификатор доступа, счётчики использования, служебные номера и состояния операций. Учёт календаря связывает идентификатор доступа с ключом места, содержащим координаты. Поэтому отсутствие имени не делает эти записи полностью анонимными. Эти данные нужны для ограничения запросов и защиты от повторного списания; это не полная копия сада.

При использовании покупок Apple сведения о покупке и её статусе нужны для проверки доступа к Pro. GrowLog не запрашивает полные реквизиты платёжной карты. Отмена подписки, отключение доступа устройства и удаление данных являются отдельными действиями.

Хранение служебных данных

Устаревшие записи учёта лимитов очищаются при последующих обращениях. Для неактивного доступа точный срок удаления не установлен. Общие климатические профили не имеют автоматического срока удаления. Записи, необходимые для предотвращения злоупотреблений и повторного списания, рассматриваются отдельно при запросах на удаление. Сроки хранения журналов и резервных копий поставщиков могут отличаться от сроков хранения ответа ИИ.

Напоминания и удаление

Напоминания планируются локально через iOS с вашего разрешения. Название сада и текст задачи могут быть видны на экране блокировки; отображением превью управляют настройки уведомлений iPhone.

Удаление местоположения и всех данных в GrowLog действует на соответствующие локальные данные. Удаление всех данных также сбрасывает локальное согласие на ИИ. Это не отменяет подписку Apple и не удаляет автоматически серверные климатические профили, учёт лимитов, журналы поставщиков или экспортированные файлы. Для запроса об обработке или удалении серверных данных используйте контакт в начале документа. В обращении опишите функцию и данные; не присылайте ключи доступа, пароли или полную копию сада. Оператор проверяет связь запроса с данными и применимые обязанности по их сохранению. Отключение доступа и удаление данных рассматриваются отдельно.

В текущем приложении нет рекламных SDK, межприложного отслеживания или SDK продуктовой аналитики. Сетевые провайдеры могут обрабатывать технические данные соединения, включая IP-адреса. Серверные обращения не объявляются полностью анонимными. По вопросам доступа, исправления, удаления данных и применимых прав обращайтесь по указанному контакту.
